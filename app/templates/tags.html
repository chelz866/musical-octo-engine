Tags

Every untyped tag found across your library (fandom, character, relationship, and freeform tags all mixed together -- there's no way to tell them apart from the file alone; relationship tags start out guessed from the "/" or "&" convention between names, which can misfire on an ordinary tag like "Hurt/Comfort" -- reclassify those here). Classifying one here applies to every work that has it.

Tag wrangling links a same-category hierarchy: "Merge selected into" folds every checked tag into one canonical tag everywhere -- display, Tags-page counts, and classification -- so it stops appearing here as its own row (undo it from the "Wrangled Tags" list below). "Make selected children of" keeps each checked tag as itself but requires the parent to be the same category (a Fandom's parent is always a Fandom, a Freeform tag's parent always Freeform, etc) -- filtering or excluding Downloads by the parent also matches works only tagged with the child, at any depth in the chain.

Fandom/Character/Relationship association is separate from that hierarchy, and cross-category by design: every Character, Relationship, and Freeform tag has its own "Fandom" dropdown (defaulting to "No Fandom", inherited down a same-category chain unless a tag sets its own), a Relationship gets one Character dropdown per "/"-or-"&" name part, and a Freeform tag can be linked to any number of Characters and Relationships. Once a Fandom is set, Downloads filtering by that Fandom also matches works using the associated Character/Relationship/ Freeform tag, even when the epub's own raw tags never mention the Fandom directly.
